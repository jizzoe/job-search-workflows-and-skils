# Job Search Workflows & Skills

An AI-assisted toolkit for landing a job — built first and foremost for its owner, and shared openly for anyone else running the same gauntlet.

## Why this exists

After 8 years at a major healthcare IT company, I was laid off. This repo is where I'm building the AI assistant skills, automations, and workflows I need to search for, apply to, and land my next role — resume tailoring, application tracking, interview prep, outreach, research, and whatever else the search demands.

## Goals

1. **Primary: get me hired.** Every skill and workflow here exists first to serve that goal. This is a working toolkit, not a demo.
2. **Secondary: help others in the same boat.** Layoffs are common and the job search process is repetitive, stressful, and full of busywork that AI assistants are well-suited to help with. Where it makes sense, patterns built here are extracted and generalized so they're reusable outside my specific situation.

## What's inside

Expect a growing collection of AI assistant skills, prompts, automations, and supporting scripts focused on the mechanics of job hunting. Structure and organization are still evolving as the collection grows.

## Use it, fork it, steal it

If anything here is useful to you — fork it, copy it, adapt it, lift the code or the pattern outright. No attribution required, no permission needed. If you're job hunting too, I hope this saves you some time.

## Status

Early and actively evolving. Built in the open while the search is happening.
